# 发票报销单生成器（网页版）

纯前端网页：发票解析、费用报销单生成、PDF 合并、Excel 导出，**全部在浏览器本地完成，文件不会上传到任何服务器**。

## 怎么用

1. 打开网页
2. 选择发票 PDF（可多选）
3. 核对清单里的科目，需要改的直接改
4. 选版式（原始尺寸 / A4 一页两版 / A5 一页一版），点生成
5. 下载 zip：`费用报销单.pdf` + `发票汇总.xlsx` + `报销材料合并.pdf`

## 说明

- 支持 PDF 发票；补充附件支持 jpg / png / bmp / pdf
- 科目匹配规则在 `科目字典.json`，可直接改这个文件，不用改代码
- 建议使用最新版 Chrome / Edge
- 所有依赖（pdf.js、pdf-lib、字体）都放在 `lib/` 里，不依赖外部 CDN
